引入「三态策略」，让「跟随全局 / 全部启用 / 自定义」成为显式状态。

**变更**
- 存储结构从 v1 的 `overrides` 升级为 v2 的 `global` + `workspaces`（自动迁移，配置不丢）
- 全局新增 `mode`：`all`（全部启用，缺省值）| `custom`（自定义）
- 每个工作区新增 `mode`：`follow`（跟随全局，缺省值）| `all` | `custom`
- 设置页新增「全局配置」入口（工作区列表最前），点进去与其他工作区一致
- 工作区选择与插件列表之间新增策略行，三选一；全局面板只有两选一
- `workspace_gate` 工具新增 `action=mode` 与 `action=global`
- 新增 HTTP 路由 `POST /mode` 与 `POST /global`
- 版本号 `0.1.3 → 0.2.0`

**行为差异**
- **`mode` 是唯一决定行为的字段，`hidden` 只是数据。** 切走「自定义」时清单原样保留，
  只是不再生效；界面勾选会置灰，切回来就能继续用。不再需要「先备份再切」。
- **执行优先级**：工作区 `custom` > 工作区 `all` > 全局 `custom` > 全部放行。
  父子目录取最长祖先前缀，命中最深的那个说话。
- **`follow` 只跟全局，不继承父工作区。** 父目录 `custom`、子目录 `follow` 时，
  子目录套用全局清单。这是有意设计，界面会明确标注继承来源。
- **全局缺省即「全部启用」**：文件里没有 `global` 字段就是放行，与刚装插件时一致。
- **写接口返回 `effective`**：`/apply`、`/mode`、`/global`、`action=set/mode` 都会返回
  这次实际生效的条数。给一个「全部启用」的目录写清单时它会返回 0，调用方当场就能发现
  「存了但没生效」，不必再查一次状态。
- **删除全局配置必须显式 `clear:true`**。此前无参调用会静默清空整份全局配置并返回成功。
- **保存提示不再谎报成功**：勾了插件却因策略不生效时，提示改为「已保存，但当前策略下不会生效」。
- **新增目录默认「自定义」**：手动添加的目录本就是要单独配置它，此前默认「跟随全局」
  会让勾选在保存时全部丢失。

**安装**
```bash
# GitHub（任何机器）
dsh plugin --profile <your-profile> add github:Anicomig/dsh-workspace-gate#v0.2.0
```
装完仍需在插件页启用 bundle。

**升级说明**
已有的 `workspace-gate.json` 会在读取时自动迁移：旧的 `overrides[dir]` 转成
`workspaces[dir] = { mode: "custom", hidden: [...] }`，下次任意保存即写成 v2。
**不需要手工迁移，配置不会丢。**
